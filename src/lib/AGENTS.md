## Club Map venue data
- Overpass venue search runs three smaller queries (gyms, clubs/centres, sports facilities) on different mirrors, keeps any that succeed and dedupes by element id; failed groups retry up to 3 times with growing waits (1.5s/4s/8s) on rotated mirrors; identical searches are shared and cached — one huge query timed out and hid live venues.
- Overpass venue queries go through the `/api/public/overpass` relay (read-only JSON queries, size-capped) before direct mirrors — browser CORS blocks and missing user-agent headers made mirrors fail.
- Curated UAE venues live in `public.venues` (public read, admin write) and load first on the Club Map; live OpenStreetMap results only add venues not already listed — the map never depends on busy free services. A live venue counts as the same place as a listed one when within ~90 m regardless of name, or same normalized name within ~550 m (live) / ~2 km (directory pin, since those are approximate) — OSM often maps a club and its grounds as separate elements.
